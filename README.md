# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.
# SkillProof-AI

## 🚀 About the Project

SkillProof-AI is an AI-powered skill assessment and verification platform designed to help users assess their skills and generate reliable digital proof of their abilities.

The platform provides a simple and user-friendly way to evaluate skills through role-based assessments and generate meaningful skill results.

## 🎯 Problem Statement

Traditional certificates and resumes do not always demonstrate a person's actual practical skills.

SkillProof-AI addresses this problem by providing an AI-based platform that evaluates skills through assessments and provides measurable skill results.

## 💡 Our Solution

SkillProof-AI allows users to:

- Select a relevant skill or role
- Attempt skill-based assessments
- Get evaluated results
- Understand their skill level
- Generate digital proof of their skills

## ✨ Key Features

- Role-based skill assessment
- AI-assisted evaluation
- Skill scoring
- User-friendly interface
- Digital skill proof
- Fast assessment results
- Practical skill verification
