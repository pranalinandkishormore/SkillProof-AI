SkillProof-AI Deployment Guide

Backend Deployment

The backend is deployed using Render.

Backend Configuration

- Service Type: Web Service
- Runtime: Node.js
- Root Directory: Backend
- Build Command: npm install
- Start Command: npm start

Frontend Deployment

The frontend will be deployed using Vercel / Netlify.

Deployment Steps

1. Connect the GitHub repository.
2. Select the frontend project.
3. Configure the required build settings.
4. Deploy the application.
5. Test the live URL.

Final Testing

Before the final hackathon demo, verify:

- Frontend loads correctly.
- Backend is reachable.
- API requests work.
- Assessment works.
- Results are displayed correctly.
- No major errors occur.
